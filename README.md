# 8-Bit ALU Design and RTL-to-Gate-Level Synthesis

## Project Overview
Designed and simulated an 8-bit Arithmetic Logic Unit (ALU)
using Verilog HDL and synthesized it using Yosys.

## Operations
1. Addition
2. Subtraction
3. AND
4. OR
5. XOR
6. NOT
7. Left Shift
8. Right Shift

## Tools Used
- Verilog HDL
- Icarus Verilog
- Yosys
- GTKWave

## Project Files
- alu.v - RTL design
- alu_tb.v - Testbench
- alu_gate.v - Synthesized netlist
- alu_circuit.png - Circuit diagram

## Results
All eight ALU operations were simulated successfully.
RTL synthesis was completed using Yosys.
